
# FAQ – Frequently Asked Questions

### Does the module work with PrestaShop 8 and 9?
Yes, it is fully compatible.

### Can I customize the blog layout?
Yes — the module uses Smarty and hooks, so you can override templates in your theme.

### Does the module support SEO?
Yes — it includes meta tags, friendly URLs, schema.org and SEO widgets.

### Can I add the blog to the main menu?
Yes — simply add a link to the blog homepage.
