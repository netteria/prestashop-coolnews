# CoolNews Module Configuration

After installation, go to **Modules → CoolNews → Configure**.

## 1. General Settings
- Enable/disable blog
- Number of posts per page
- Pagination
- Enable comments (if available)

## 2. SEO
- Meta title
- Meta description
- Friendly URLs
- URL structure

## 3. Appearance
- Thumbnail settings
- Post list layout
- Single article layout

## 4. Widgets
- Latest posts
- Popular posts
- Categories
- Tags

## 5. Hooks
The module supports:
- displayHome  
- displayLeftColumn  
- displayRightColumn  
- displayFooter  
- displayHeader
