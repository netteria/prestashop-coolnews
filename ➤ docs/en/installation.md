# Installing the CoolNews Module

1. Log in to your PrestaShop back office.
2. Go to **Modules → Module Manager**.
3. Click **Upload a module**.
4. Select the ZIP package you received after purchase.
5. After installation, go to the module configuration page.

## Requirements
- PrestaShop 1.7 / 8 / 9
- PHP compatible with your shop version
- Write permissions for `/modules`

## Troubleshooting
- Check PrestaShop logs if installation fails.
- Verify PHP version and server configuration.
- Ensure correct folder permissions.
