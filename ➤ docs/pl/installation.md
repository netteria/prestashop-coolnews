# Instalacja modułu CoolNews

1. Zaloguj się do panelu administracyjnego PrestaShop.
2. Przejdź do **Moduły → Menedżer modułów**.
3. Kliknij **Prześlij moduł**.
4. Wybierz paczkę ZIP otrzymaną po zakupie.
5. Po instalacji przejdź do konfiguracji modułu.

## Wymagania techniczne
- PrestaShop 1.7 / 8 / 9
- PHP zgodny z wersją Twojego sklepu
- Uprawnienia zapisu w katalogu `/modules`

## Rozwiązywanie problemów
- Jeśli instalacja się nie powiedzie, sprawdź logi PrestaShop.
- Upewnij się, że serwer spełnia wymagania PHP.
- Sprawdź uprawnienia katalogów.
