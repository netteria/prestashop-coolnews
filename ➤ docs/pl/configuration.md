# Konfiguracja modułu CoolNews

Po instalacji przejdź do **Moduły → CoolNews → Konfiguracja**.

## 1. Ustawienia ogólne
- Włącz/wyłącz blog
- Liczba wpisów na stronę
- Paginacja
- Włącz komentarze (jeśli dostępne)

## 2. SEO
- Meta title
- Meta description
- Przyjazne adresy URL
- Struktura linków

## 3. Wygląd
- Miniatury zdjęć
- Układ listy wpisów
- Układ pojedynczego artykułu

## 4. Widgety
- Ostatnie wpisy
- Popularne wpisy
- Kategorie
- Tagi

## 5. Hooki
Moduł obsługuje m.in.:
- displayHome  
- displayLeftColumn  
- displayRightColumn  
- displayFooter  
- displayHeader
