# SEO w module CoolNews

Moduł został zaprojektowany z myślą o pozycjonowaniu.

## Funkcje SEO
- Przyjazne adresy URL
- Meta title i meta description
- Struktura nagłówków H1–H3
- Schema.org Article
- Linkowanie wewnętrzne
- Widgety wspierające indeksację

## Rekomendacje
- Twórz unikalne treści
- Używaj kategorii i tagów
- Linkuj między artykułami
- Dodaj blog do menu głównego
